Social Media API
Objetivo

Desenvolver uma API REST inspirada em redes sociais modernas, utilizando Django e Django REST Framework, consumida por uma aplicação Flutter e uma aplicação Web.

O projeto possui como objetivo demonstrar conhecimentos em:

-Arquitetura REST
-Versionamento de API
-JWT
-Clean Architecture
-Boas práticas
-Docker
-Testes automatizados
-Documentação
-Deploy
-Tecnologias

Backend

-Python 3.12
-Django
-Django REST Framework
-PostgreSQL
-Docker

Frontend
-Flutter
-Tailwind

Funcionalidades

-Cadastro
-Login
-Perfil
-Publicações
-Comentários
-Curtidas
-Compartilhamentos
-Reposts
-Seguir usuários
