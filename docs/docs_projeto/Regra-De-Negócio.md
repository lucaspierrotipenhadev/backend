Regras de Negócio - RN

Regras de Negócio (Publicação) -RN

RN001: Um usuário não pode seguir a si mesmo
RN002: Um usuário pode seguir outro usuário somente uma vez
RN003: AO excluir um usuário, suas publicações permanecerão armazenadas utilizando exclusão lógica
RN004: Uma publciação poderá ter texto e mídia
RN005: Uma publicaão poderá existir apenas com mídia
RN007: Uma publicação sem texto e sem mídia não poderá ser criada
RN008: Somente o autor poderá editar e excluir sua publicação

---------------------------------------------------------------------

Regras de Negócio (Curtidas) -RN

RN010: Um usuário só poderá curtir uma publicação uma única vez
RN011: Ao clicar na curtida duas vezes, ela será removida

---------------------------------------------------------------------

Regras de Negócio (Comentários) -RN

RN012: Comentários poderão ter respostas
RN013: Uma resposta pertence a um usuário
RN014: Não existe limite de níveis de resposta
