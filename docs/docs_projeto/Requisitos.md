Requisitos Não Funcionais - RNF

Requisitos Não Funcionais (API) - RNF:
RNF001: A API deverá seguir uma arquitetura REST
RNF002: A autenticação deverá utilizar JWT
RNF003: Todas as datas deverão seguir UTC
RNF004: As senhas serão armazenadas utilizando hash
RNF005: A API deverá possuir versionamento
RNF006: Toda rota protegida deverá exigir autentiação

---------------------------------------------------------------------

Requisitos Funcionais -RF:
RF001: O usuário poderá criar uma conta
RF002: O usuário poderá fazer login
RF003: O usuário poderá criar, editar e excluir suas própias publicações
RF004: O usuário poderá comentar, dar like, repostar, e enviar uma publicação
RF005: O usuário poderá dar like, e comentar comentários
RF006: O usuário poderá seguir ou não seguir outros usuários.
